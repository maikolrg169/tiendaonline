Prompt para Desarrollo de E-commerce CMS con Google Sheets
Contexto y Rol
Actúa como un Desarrollador Full Stack Senior experto en Next.js (App Router) y en el uso de la API de Google Sheets (google-spreadsheet o googleapis) como base de datos principal. Tu objetivo es desarrollar un E-commerce tipo CMS (Sistema de Gestión de Contenidos).
Nota: quiero que la web sea responsiva y tenga PWA.
El sistema no debe tener información fija en el código. El administrador debe poder configurar y personalizar la tienda por completo desde un panel de control, y toda esta información, así como los productos y pedidos, se leerá y escribirá exclusivamente en un documento de Google Sheets.

Estructura de la Base de Datos (Pestañas y Columnas del Sheet)
El archivo de Google Sheets tendrá las siguientes pestañas (hojas), donde la primera fila siempre será el encabezado:

Hoja Configuracion: Funcionará con formato clave-valor.

Columnas: Clave, Valor

Ejemplo de Claves: NombreTienda, ColorPrimario, ColorSecundario, TasaDolar, TelefonoContacto, TextoNosotros.

Hoja Productos:

Columnas: ID, Nombre, Descripcion, Precio_USD, Imagen_URL, Categoria, Stock, Estado (Activo/Oculto).

Hoja Pedidos:

Columnas: ID_Pedido, Fecha, Nombre_Cliente, Telefono_Cliente, Metodo_Envio, Metodo_Pago, Referencia_Pago, Total_USD, Total_Bs, Estado_Pedido (Pendiente/Pagado/Enviado), Productos_Carrito (Aquí se guardará un string en formato JSON con los productos comprados para evitar tablas relacionales complejas).

Hoja Envios:

Columnas: ID_Envio, Nombre_Empresa (MRW, Zoom, Tealca, Delivery), Tarifa_USD, Estado (Activo/Inactivo).

Características del Backend (Panel de Administración - El CMS)
Este panel (protegido con usuario/contraseña usando JWT o NextAuth) debe permitir operaciones CRUD directamente sobre las hojas de cálculo:

Configuración: Actualizar las filas de la hoja Configuracion (ej. cambiar los colores de la web o la tasa del dólar).

Gestión de Inventario: Agregar, editar o eliminar filas en la hoja Productos.

Gestión de Ventas: Leer la hoja Pedidos para revisar compras, verificar números de referencia de Pago Móvil y cambiar la columna Estado_Pedido.

Características del Frontend (La Vitrina Pública)

Diseño Dinámico: Los estilos (Tailwind CSS) deben adaptarse leyendo ColorPrimario y ColorSecundario desde la hoja Configuracion.

Catálogo y Carrito: Cuadrícula de productos mapeada desde la hoja Productos. Precios en Bs calculados dinámicamente multiplicando el Precio_USD por la TasaDolar obtenida de la hoja Configuracion.

Checkout Adaptado: Formulario para procesar el carrito, solicitar datos del cliente, método de pago (Pago Móvil) y referencia. Al enviar, se debe crear una nueva fila en la hoja Pedidos con los datos y el carrito convertido a JSON en la columna Productos_Carrito.

Instrucciones de Entrega

Proporciona el archivo de utilidad o servicio (ej. lib/googleSheets.js o .ts) para inicializar la conexión con Google Sheets usando las variables de entorno.

Define la estructura de carpetas en Next.js separando la app pública (/) del panel de administración (/admin).

Muestra el código de la función para obtener los productos (GET) y la función para crear un nuevo pedido (POST) escribiendo en la hoja correspondiente.
